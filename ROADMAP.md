# Roadmap

This roadmap covers 16 October 2026 through at least 16 October 2027.

- Preserve the documented public navigation and repository scope.
- Maintain regression tests for browser behavior and workflow trust boundaries.
- Review dependency updates and security findings, including optional operator tooling.
- Improve accessibility and complete browser testing before claiming those properties.
- Establish backup-maintainer access only through an authorized, tested process.

Discuss priorities through issues and pull requests. These are plans, not completed features.

## Non-goals

No device control, credentials in public pages, automatic changes to another project's infrastructure, synthetic application packages, or weakening of required reviews.
