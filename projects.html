    Venus OS D-Bus services8

    Bridges for native com.victronenergy.* services and optional D-Bus diagnostics. Follow each package’s installation guide before deploying to a GX.

    dbus-mqtt-battery↗

    MQTT → D-Bus bridge for JBD BMS batteries on Venus OS, with DVCC support.

    Pythonbatterydvccorg

    dbus-tasmota-pv↗

    Tasmota power meter → D-Bus PV inverter bridge. Turns a smart plug into a PV meter.

    Pythonpv-invertertasmotaorg

    dbus-esphome-grid-sensor↗

    ESP32 CT sensor for grid power monitoring, exposed as a D-Bus service on Venus OS.

    Pythonesp32gridorg

    dbus-emporia-vue↗

    Emporia Vue submeter channels as individual D-Bus AC loads, fed by Home Assistant WebSocket power data.

    Pythonsubmeteringacloadorg

    dbus-virtual-battery↗

    Derived battery measurements for chains without a BMS. Consumes the MQTT battery driver’s freshness contract; does not establish physical BMS permission.

    Pythonderived-telemetryorg

    dbus-ev↗

    Vehicle telemetry from Mercedes or Home Assistant, plus optional integrated Mercedes charger telemetry. Read the migration guide before replacing the archived standalone charger.

    Pythonorg

    dbus-pump↗

    Home Assistant water tank, pump and valve data exposed as native Venus services, with the water automation and command path owned by this bridge.

    Pythonorg

    dbus-event-log↗

    Optional D-Bus event recorder with SQLite/TimescaleDB, MQTT and CLI tools. Method capture requires explicit bus permissions; it is not a lossless audit or a native SetupHelper package.

    Pythonaudit-logtimescaledborg

    Sensing & firmware2

    ESP32 firmware and reference patterns for the hardware side of the stack.

    esphome-jbd-bms-mqtt↗

    ESP32 Bluetooth proxy for JBD BMS batteries, publishing cell voltages and SOC to MQTT.

    ESPHomeblejbd-bmsorg

    esphome-ble-sensor-patterns↗

    Production-ready ESPHome patterns for BLE sensors — iBeacon, Eddystone, custom services, passive scanning, HA integration.

    ibeaconxiaomireference4alvit

    Control & policy2

    Inverter control and independently enabled thermostat coordination.

    inverter-control↗

    Grid-zero feed-in control with Home Assistant integration and web dashboard. The core ESS brain of the stack.

    Pythonessquattroorg

    inverter-climate↗

    Native Venus OS thermostat integration via Home Assistant and Google Nest. Publishes room temperature and optional setpoint and Heat/Off controls in the stock GUI v2 Switch pane and VRM Remote Console. Energy-aware preheating is enabled separately; observation is the default.

    PythonthermostatSetupHelperorg

    Dashboards & clients5

    Web, native and read-only public clients. Pick by deployment target.

    inverter-dashboard-go↗

    Real-time dashboard as a single Go binary — runs directly on the Cerbo GX, optional direct Home Assistant control.

    Gowebsocketcerboorg

    inverter-dashboard↗

    The original Python dashboard, shipped as Docker image alvit/inverter-dashboard for NAS deployments.

    Pythondockerorg

    inverter-dashboard-vue↗

    Shared Vue 3 SPA and reusable UI component library for the Go, Python and desktop dashboards.

    Vuespaui-libraryorg

    inverter-desktop↗

    Tauri desktop client wrapping the Vue dashboard, with native installers per release.

    Vuetauriorg

    inverter-web-vitrine↗

    Read-only public status page backed by inverter-gateway through an authenticated server-side proxy. Access credentials stay off the browser.

    org

    Voice & displays2

    Read-only reports from inverter-gateway. Energy statistics and freshness remain owned by the gateway; these adapters handle presentation.

    amazon-echo-home-voice↗

    Alexa custom skill backend for energy speech and screen cards. Uses authenticated gateway reports; developer setup, certification and physical device acceptance are separate steps.

    Python4alvit

    google-home-voice-stats↗

    Standalone Cast video and speech reports using the gateway’s read-only energy API. Optional Home Assistant/Matter triggers add a voice entry point; Cast alone does not add voice commands.

    Python4alvit

    Forecasting & AI3

    LangGraph solar forecasts from weather and historical generation. Connecting a forecast to live control requires a configured and tested consumer.

    Pythonopenmeteoarima4alvit

    energy-data-rag-pipeline↗

    RAG pipeline over Victron documentation — pgvector, LangChain, FastAPI.

    Pythonpgvectorrag4alvit

    mcp-venus-os↗

    MCP server for Venus OS management — D-Bus, MQTT, and safety-constrained control for AI assistants.

    Pythonmcpclaude4alvit

    Observability3

    mqtt-observability-opentelemetry↗

    inverter-monitoring↗

    Pythontig-stackgrafanaorg
