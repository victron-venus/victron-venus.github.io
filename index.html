    Flagship

    Small tools.
    Purposeful building blocks.

    These projects cover control, telemetry, interfaces and development tooling. Deployment and device verification vary by component; see the documented evidence and remaining checks.

    inverter-control↗

    Grid-zero feed-in control for Victron inverters. Reads configured Venus D-Bus measurements and applies validated ESS setpoints; dashboards are separate clients.

    Pythonessgrid-zeroorg

    dbus-mqtt-battery↗

    Bridges JBD BMS batteries published over MQTT onto Venus OS D-Bus, with full DVCC support. No-BMS chains get dbus-virtual-battery.

    Pythonbatterydvccorg

    inverter-dashboard-go↗

    Real-time web dashboard as a single Go binary that runs directly on the Cerbo. Same role as inverter-dashboard, zero Docker.

    Goreal-timewebsocketorg

    solar-forecast-langgraph↗

    LangGraph workflow that forecasts generation from OpenMeteo weather and historical inverter data. Live control requires a separately configured and tested consumer.

    Pythonlanggraphopenmeteo4alvit

    mcp-venus-os↗

    Companion MCP server for configured Venus OS D-Bus and MQTT access. Write access depends on the enabled tools, permissions and deployed device policy.

    Pythonmcpai4alvit

    venus-os-ci-toolkit↗

    Reusable GitHub Actions workflows for adopting projects: lint, test, coverage, govulncheck and Scorecard — pinned by commit SHA.

    ciactionsorg
